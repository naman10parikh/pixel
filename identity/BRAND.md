# pixel — BRAND

## Name rationale

**pixel** is the smallest addressable unit of a screen — the atom every interface is built
from. Every button, every gradient, every hero is, at the bottom, pixels. The name *is* the
workflow: pixel is the fleet's frontend employee, the one that owns what you see. Lowercase,
from the light / relatable / animate naming family (D4/D5) — a sibling to Spark and Ribbon,
not a heavy industrial name.

## Symbolic color — warm-black editorial + ONE OKLCH accent

pixel eats its own dog food: the brand is built to the same taste gate pixel enforces on
everything it ships (`pixel audit` → `impeccable detect`, exit 0).

- **Base — warm black `#141312`.** Not pure black `#000`, not near-black `#09090b`. Untinted
  black is the #1 machine-detectable AI-slop tell (impeccable flags it deterministically);
  warm-black reads editorial and intentional (OPINIONS O-HS1).
- **Ink — `zinc-100` / `zinc-200` on dark.** Never pure-white `#fff` text on the warm-black
  field — softened ink, not maximum contrast (O-HS5).
- **Accent — ONE moment per surface, OKLCH, warm amber `oklch(0.78 0.15 70)` (`#E8A33D`).**
  A single brand color-moment, on a Radix 12-step scale with a purpose per step (1–2 bg,
  3–5 component, 6–8 borders, 9–10 solid, 11–12 text). Amber is deliberately OFF the
  AI-default brand hue — the training-data prior Adam Wathan publicly apologized for seeding
  into the corpus (the violet-family Tailwind-UI button color), which the median model now
  emits as the "statistically most correct option" (OPINIONS O-F1). pixel **hard-overrides**
  the violet-family accent prescribed by energy's own `react.md` (see brain O-F1 for the
  exact tokens and the Wathan quote): honoring that default would actively fail the
  flagship's bar (not-looking-AI-made). Warm amber is the chosen accent; the warm-black
  baseline stands regardless of accent.
- **Type — Instrument Serif (display) + Poppins (body).** Serif + sans pairing is the single
  highest-impact anti-AI-generated-look move; "Inter for everything" is an explicit slop
  rule (O-HS2 / O-F6).
- **Layout — bento / asymmetric.** Never symmetric card grids; never cards-nested-in-cards;
  never a rounded-square icon tile above every heading (O-HS3 / O-HS4).
